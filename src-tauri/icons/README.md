# أيقونة التطبيق — مصدرها الهوية، ولا تُرسَم هنا

المصدر المعتمد الوحيد:

```
ملف الهوية · صفحة «03 — App Icon» · المكوّن Brand/App Icon/Master
```

## علامتان لا واحدة

الهوية تفصل بينهما صراحةً، وصفحة ‎02‎ تجمعهما في قسمٍ اسمه
«‏Brand Mark + App Icon / علامة الهوية + أيقونة التطبيق»:

| الأثر | الموضع | أين يُستعمل |
|-------|---------|-------------|
| **الرسم** (سـ/نـ) | صفحة ‎02 — Logo System | علامة الهوية داخل التطبيق وفي الشعارات المركّبة |
| **`>_`** | صفحة ‎03 — App Icon | أيقونة تطبيق macOS وحدها |

وكان هذا المجلد يحمل **الرسم** أيقونةً للتطبيق، وهو خلطٌ بين الاثنين: صفحة ‎03‎
كاملةً — بسلّم مقاساتها، وشبكة بنائها، ومحاكاة الـDock وSpotlight، ولوح
التصدير — لا تعرض إلا `>_`. وصفحة ‎11‎ (تطبيقات العلامة) تستعملها كذلك في كل
سياقٍ تظهر فيه أيقونة التطبيق.

## البناء المعتمد

| العنصر | القيمة |
|--------|--------|
| الأرضية | `#0F0F1E` — Brand Navy |
| الرمز `>_` | `#FAF8F5` — Warm Paper |
| نقطة التنفيذ | `#D0470D` — Execution Orange |
| نصف قطر الزاوية | ‎23.85٪‎ متّصل (‏`244.18` عند مصدر ‎1024‎) |

## معالجة التصدير — حافةٌ من كتلة الأيقونة، ولا ظلّ

لوح التصدير في صفحة ‎03‎ هو الفاصل: نُسَخه الخمس تحمل `exportSettings` صريحة
(‏PNG بمقياس ‎1‎ ولاحقات ‎-1024‎ … ‎-64‎).

- **الحدّ الخارجي** — `strokeAlign: INSIDE`، وسماكته نسبةٌ ثابتة من المقاس عند
  كل نسخة (‏‎1.5385٪‎: ‎15.75/1024‎ و‎7.88/512‎ … و‎0.98/64‎). ولونُه اليوم
  **لونُ الأرضية نفسها** `#0F0F1E` بعد أن كان `#FFFFFF`: فالحافة تُقرأ امتدادًا
  لسطح الأيقونة لا إطارًا مرسومًا حولها. وهو **داخل** الشكل فلا يكسر تربيعه.
- **الظلّ المُسقَط** — يمتدّ خارج الشكل، فتصديرُ النسخة يخرج ‎1024×1058‎ لا
  ‎1024×1024‎: مقاسٌ غير مربّع لا تقبله حزمة أيقونات macOS أصلًا. ثم إن النظام
  يركّب ظلَّه في الـDock، فخبزُ ظلٍّ ثانٍ يضاعفه. **لا يُشحن**.

فما يُشحن: الأرضية والزاوية والرمز والنقطة — مربّعًا نظيفًا بحافةٍ متجانسة.

## سيّدٌ واحد في كل المقاسات

صفحة ‎03‎ تقولها: «‏one Master, many sizes — geometry preserved, optics adjusted
only when needed». فالبلاطة هي الشكل من ‎1024‎ إلى ‎16‎.

وهذا **يبطل الثنائية السابقة** (علامةٌ مجرّدة حتى ‎64px‎ وبلاطةٌ من ‎128px‎) التي
كان هذا الملف يصفها ويحرسها الاختبار.

## ⚠️ لا تُشغِّل `tauri icon`

يكتب أصولَ ويندوز (`icon.ico`، `Square*Logo.png`) وهذه حزمة macOS وحدها،
ويشتقّ المقاسات باستنساخٍ لا يطابق ما صُدِّر من الهوية. `naffith.iconset/`
منسوخٌ هنا كاملًا كي يبقى بناء `.icns` جمعًا للمقاسات لا اشتقاقًا منها:

```bash
iconutil -c icns src-tauri/icons/naffith.iconset -o src-tauri/icons/icon.icns
```

## الحارس

`src/icons.source.test.ts` يثبّت بصمة كل ملف هنا، ويقيس قناة الشفافية ليؤكّد أن
كل مقاسٍ بلاطةٌ مستديرة — لا علامةٌ مجرّدة ولا مربّعٌ حادّ. فتغيير الأيقونة يبقى
ممكنًا، لكنه فعلٌ مقصود تُحدَّث معه البصمات في الالتزام نفسه.
