# نظام التصميم · Design System

الطبقة المرجعية الوحيدة لهوية **نَفِّذ**. كل سطح في المشروع — دليل الهوية،
الموقع التعريفي، النماذج، وتطبيق سطح المكتب — يستورد هذه الملفات ولا يعرّف قيمًا خاصة به.

```
design-system/
├── tokens.css     ← المصدر الوحيد للقيم (ألوان، خطوط، مسافات، حركة…)
├── base.css       ← التصفير، الطباعة، ثنائية الاتجاه، التركيز، المكوّنات الأساسية
├── fonts.css      ← Cairo + Almarai + JetBrains Mono مُضمّنة محليًا
├── fonts/         ← ملفات woff2 (‏292KB إجمالًا)
├── icons.svg      ← مجموعة الأيقونات · شبكة 24 · سماكة 1.5
├── logo.svg       ← العلامة بكل مقاساتها البصرية والأقفال
└── contrast.md    ← جدول التحقق من التباين (WCAG)
```

## الاستخدام

```html
<link rel="stylesheet" href="../design-system/fonts.css">
<link rel="stylesheet" href="../design-system/tokens.css">
<link rel="stylesheet" href="../design-system/base.css">
```

الترتيب مُلزِم: `tokens` قبل `base`، و`base` قبل أي أنماط خاصة بالصفحة.

## القواعد غير القابلة للتفاوض

### ١. الرموز الدلالية فقط

المكوّن لا يشير أبدًا إلى قيمة خام. `--ink-700` و`--ember-400` طبقة أولية داخلية.

```css
/* ✗ */  color: #272831;        border: 1px solid var(--ink-200);
/* ✓ */  color: var(--text-primary);  border: 1px solid var(--border-subtle);
```

### ٢. اللون لا يحمل المعنى وحده

كل حالة (نجاح، خطأ، تحذير، معلومة، ملغاة) تقترن دائمًا بأيقونة **مختلفة الشكل** ونص.
الأيقونات مصمّمة لتُميَّز بالشكل وحده: صح داخل دائرة، ✕ داخل دائرة، مثلّث، «i» داخل
دائرة، شَرطة داخل دائرة.

### ٣. الخصائص المنطقية لا الفيزيائية

المنتج يعمل بالعربية (RTL) والإنجليزية (LTR) من نفس الشيفرة.

```css
/* ✗ */  border-right: 3px solid;  margin-left: auto;   padding-right: 16px;
/* ✓ */  border-inline-start: 3px solid;  margin-inline-start: auto;  padding-inline-start: 16px;
```

### ٤. لا تباعد أحرف على العربية أبدًا

العربية خط متصل، و`letter-spacing` الموجب يفكّ الوصلات ويُتلف الكلمة.
`--tracking-wide` مخصّص للنصوص اللاتينية المعزولة عبر `.lat-track` فقط.
كذلك `text-transform: uppercase` بلا معنى في العربية.

### ٥. المحتوى التقني يبقى LTR داخل RTL

الأوامر والمسارات والرايات ومتغيّرات البيئة وأسماء الفروع واختصارات لوحة المفاتيح:

```html
<span class="path">~/Projects/my-app</span>
<code>git commit -m "…"</code>
```

كلاهما يطبّق `direction: ltr` و`unicode-bidi: isolate`. العزل ضروري: بدونه تقفز
النقطة أو الشرطة إلى الطرف الخاطئ من الجملة العربية.

الأربطة (ligatures) مُعطّلة في الخط أحادي المسافة: دقّة الأمر الحرفية أهم من `→`.

### ٦. سطح سَطْر داكن في الوضعين

`--command-bg` لا يتبع سمة النظام. الأمر التقني هو «الطبقة التي تحت»، فيحتفظ بمادته
في الوضع الفاتح والداكن معًا. هذا قرار مفهومي لا تقني.

### ٧. التركيز مرئي دائمًا

لا تكتب `outline: none` دون بديل. `:focus-visible` في `base.css` يوفّر حلقة تركيز
تحقق ٣:١ مقابل كل سطح يمكن أن تظهر فوقه.

## الأيقونات

```html
<script src="../design-system/sprite.js" defer></script>
...
<svg width="16" height="16" viewBox="0 0 24 24" aria-hidden="true"><use href="#i-folder"/></svg>
```

`sprite.js` يحقن الرموز في المستند، والإشارة تكون **داخل المستند نفسه**.
لا تُشِر أبدًا إلى ملف خارجي — `<use href="icons.svg#i-folder">` لا يعمل في Chrome
ولا يُظهر خطأ، بل لا يرسم شيئًا. و`viewBox` على وسم `<svg>` الخارجي إلزامي: بدونه
لا نسبة أبعاد جوهرية، فتتحول `height:auto` إلى 150 بكسل و`width:auto` إلى 100%.

- الشبكة ٢٤×٢٤ · المساحة الحيّة ٢٠×٢٠ · السماكة ١.٥ · النهايات والوصلات دائرية
- المقاسات المسموحة: `--icon-xs` ١٤ · `--icon-sm` ١٦ · `--icon-md` ٢٠ · `--icon-lg` ٢٤ · `--icon-xl` ٣٢
- كل الأيقونات ترسم بـ `currentColor`

**الانعكاس في RTL**: الأيقونات التي تحمل اتجاهًا فقط (`chevron`, `execute`,
`external`, `file-move`) تُعلَّم بـ `data-directional` على وسم `<svg>` فتنعكس تلقائيًا.
الأيقونات التي تصوّر شيئًا واقعيًا (ساعة، قفل، بحث، سلة، قرص، علامة صح، العلامة
التجارية) **لا تنعكس** إطلاقًا.

## الحركة

المفردات مستمدّة من كشف السَّطْر تحت السطح: كشف، فتح، استقرار. لا ارتداد، ولا دوران عدا حلقة تقدّم واحدة.

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--duration-instant` | 80ms | تغيّر لون، حالة hover |
| `--duration-fast` | 140ms | أزرار، حقول |
| `--duration-base` | 200ms | قوائم منسدلة، تلميحات |
| `--duration-slow` | 280ms | فتح لوحة، كشف نتيجة |
| `--duration-slower` | 400ms | انتقال بين الشاشات |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | الكشف والفتح |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | الحركة العامة |

`prefers-reduced-motion` يخفض كل المدد إلى ١ms بدل إلغائها، حتى تستمر أحداث
`transitionend` في الانطلاق ولا تتوقف أي آلة حالة. المؤشّر الدوّار يتحوّل إلى حلقة
ساكنة بدل أن يختفي — «قيد التنفيذ» يجب أن يبقى مقروءًا.

## المنصّات

`[data-platform="win"]` يرفع ارتفاعات عناصر التحكّم قليلًا لتناسب أهداف اللمس
الافتراضية في ويندوز. أزرار النافذة (إغلاق/تصغير/تكبير) خاصية نظام تشغيل لا خاصية
مستند — **لا تنعكس مع `dir="rtl"`** وتبقى في موضعها الأصلي على كل منصّة.
