الحقول

حقول عربية هادئة، مع عزل المسارات والقيم التقنية LTR. الخطأ يشرح نفسه ولا يعتمد على الحد الأحمر وحده.

height 32px

ستُضاف اللاحقة .zip تلقائيًا.

تُقرأ الشرطات والنقاط بالترتيب نفسه داخل RTL.

لا يمكن أن يحتوي اسم الملف على شرطة مائلة.

يتاح الحقل بعد منح صلاحية المجلد.

الحركة وتقليلها

كشف وفتح واستقرار من دون ارتداد. عند طلب تقليل الحركة تنهار المدد إلى 1ms وتبقى الحالة مفهومة.

80 → 400ms

يُنشأ الملف المضغوط

تظهر الخطة بحركة قصيرة ثم تستقر. لا تدور إلا حلقة التقدم الواحدة.

جارٍ قراءة إعداد النظام
80msلون أو حالة فورية
140msزر أو حقل
200msكشف أساسي
280msفتح لوحة أو نتيجة
400msانتقال شاشة

منحنى الكشف cubic-bezier(.16,1,.3,1)، والحركة العامة cubic-bezier(.2,0,0,1).
