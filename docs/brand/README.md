# مرجع الهوية · نسخة من `naffith-satr-brand-v2`

كل ما في `docs/` مرجع تطوير للقراءة فقط: لا يُستورد في الكود ولا يدخل حزمة
الإنتاج. البناء لا يخرج من `src/`، و`docs/` خارجها، فلا يصل شيء منها إلى `dist/`.
لا يُعدَّل شيء هنا بيد؛ أي تصحيح مكانه المشروع الأصل ثم يُنسخ من جديد.

| الملف | ما هو | مصدره |
| --- | --- | --- |
| `UX-SPEC.md` | مواصفة الشاشات والسلوك | `mockups-v3/` |
| `IDENTITY-AUDIT.md` | تدقيق الهوية والقواعد البصرية الملزمة | `mockups-v3/` |
| `VISUAL-REVIEW.md` | مراجعة بصرية للنماذج | `mockups-v3/` |
| `design-system/README.md` | شرح نظام التصميم وملفاته | `design-system/` |
| `design-system/contrast.md` | جداول التباين المُتحقَّق منها | `design-system/` |
| `mockups-v3/` | النموذج التفاعلي وصفحاته | `mockups-v3/` + `design-system/sprite.js` |

ورقة `mockups-v3.css` وحدها نُسخت إلى `src/design-system/` لا هنا، لأن مرحلة
التحويل ستصل إليها عبر مُعرِّف `@ds` القائم. وهي غير مستوردة بعد عن قصد.

في فهرس النموذج بطاقةٌ تشير إلى `LEGACY-MOCKUPS-AUDIT.md`: ملف لم يُنسخ عن قصد،
فهو تدقيق نماذج قديمة لا يخصّ المنتج. الرابط متروك مكسورًا كما هو — إبقاؤه أصدق
من حذف البطاقة بصمت. مكانه المشروع الأصل `naffith-satr-brand-v2/mockups-v3/`.

## فتح النموذج محليًا

الصفحات تقرأ نظام التصميم عبر `../../../src/design-system/`، فيلزم خادم من جذر
المشروع لا فتح الملف مباشرة:

```
python3 -m http.server 8000
```

ثم `http://localhost:8000/docs/brand/mockups-v3/index.html` — ومنها إلى
`prototype.html` (النموذج التفاعلي) و`design-system.html`.
